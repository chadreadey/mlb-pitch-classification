Ball or Strike?

Place a pitch, set the count and the batter, and see the chance the umpire calls a taken pitch a strike. The model is a logistic regression trained on 1.06M called pitches from 2022–24 and tested on 708K from 2025–26. Catcher's view.

Location is measured relative to the batter's own rulebook zone: xn = px / 0.83, zn = (pz − zone centre) / zone half-height, so the zone is the square [−1, 1]². The model uses polynomial terms in xn and zn, batter handedness, and the count, including count × location interactions.

Try a 3-0 count against 0-2 on the same corner pitch and watch the 50% line move. "Small" and "tall" use the 10th and 90th percentile zones from 2022–24.

Model and code: mlb-pitch-classification (coefficients in results/model_b.json). Started as a 2023 class project with Carli Kelley and Garner Hasler. Rebuild and interactive version by Chad Readey.
